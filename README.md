# Netflix Landing Page Study

A static recreation of a Netflix signup landing page using HTML, CSS, and vanilla JavaScript.

## Features

- Hero section and signup styled calls to action.
- Three interactive tabs for cancellation, supported devices, and pricing.
- A comparison table and footer navigation.
- DOM based tab selection without a frontend framework.

The signup and sign in links are placeholders. There is no authentication, billing, video catalog, or streaming backend. Prices and promotions are historical sample content, not current Netflix offers.

## View locally

Open `index.html` in a browser. No dependency installation or build step is required.

Some images and icons are loaded from external services and require an internet connection.

## Files

- `index.html`: landing page and tab content.
- `css/style.css`: presentation and layout.
- `js/main.js`: click handlers and active tab state.

This is an educational UI recreation, unaffiliated with Netflix. Netflix branding and third party assets remain the property of their owners.
